# 생활 공간의 센서 데이터를 분석해 노약자·독거인의 이상 징후를 보호자에게 알려주는 생활 안전 모니터링 서비스

보호자가 대상자의 상태를 계속 직접 확인하기 어려운 상황에서 현관, 냉장고, 침대 등 생활 공간의 센서 이벤트를 수집합니다. 수집한 기록과 생활 패턴을 바탕으로 반복 행동, 장시간 미감지 등 평소와 다른 징후를 파악하고 대시보드에서 확인할 수 있도록 합니다.

본 서비스는 의료적 진단을 제공하거나 응급 상황에 대한 대응을 보증하지 않습니다. AI 결과는 보호자의 판단과 상태 확인을 돕는 보조 정보로 사용합니다.

## 핵심 기능

- **회원 관리**: 회원가입, 로그인·로그아웃, 내 정보 조회·수정
- **대상자 관리**: 대상자 등록·조회·수정·삭제, 모니터링 시작·중지
- **센서 관리**: 센서 등록, 대상자 연결, 설치 위치·대상 물체 설정, 연결 상태 관리
- **이벤트 수집**: Raspberry Pi 등 외부 장치에서 센서 이벤트 수신 및 중복 저장 방지
- **기록 확인**: 대상자별 센서 이벤트 기록과 오늘의 타임라인 조회
- **대시보드**: 대상자의 현재 상태, 최근 활동, 센서 연결 상태를 한눈에 확인
- **AI 이상행동 감지**: 생활 패턴을 분석해 정상·주의·위험 상태와 판단 근거 제공
- **NFC 확장**: 센서와 설치 공간의 식별을 보조하는 기능 검토

## 서비스 흐름

1. 보호자가 회원가입 후 로그인합니다.
2. 모니터링할 대상자와 생활 공간 정보를 등록합니다.
3. 대상자에게 센서를 연결하고 모니터링을 시작합니다.
4. Raspberry Pi와 센서가 생활 이벤트를 서버로 전송합니다.
5. 서버가 이벤트를 저장하고 생활 패턴을 분석합니다.
6. 보호자는 대시보드와 타임라인에서 현재 상태와 이상 징후를 확인합니다.
7. 이상 징후가 발견되면 대상자의 실제 상태를 확인합니다.

## 시스템 구성

```text
Raspberry Pi / Sensor
          │ 센서 이벤트
          ▼
   FastAPI Backend ────── AWS RDS MySQL
          │                    │
          │ REST API           │ 기록 데이터
          ▼                    ▼
 React + Vite Dashboard   AI Analysis Pipeline (개발 중)
          ▲                    │
          └── 상태·판단 결과 ──┘
```
